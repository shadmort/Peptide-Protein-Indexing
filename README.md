Hate blasting proteins to search for compatible epitopes?
Here is the solution; 
  - upload a dataframe with the protein accession and peptides
  - pick a protein you'd like to index
  - PPI.ppi(dataframe, protein accession ID)
  - See your list of [Peptides]: [Index]
  - repeat for any protein accession in your dataframe
Now you have a list of the peptide position in you master protein for downstream applications.
